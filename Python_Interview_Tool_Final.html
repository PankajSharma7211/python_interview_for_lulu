Technical Interview Tool — Python / Pandas Assessment

Interviewer Guide

14 data wrangling questions across Easy, Medium and Hard. All DataFrames are pasted directly into the compiler — no file uploads needed. Keep this tab open throughout the interview.

Section 1 — Pre-Interview Checklist
📋
Ensure you have this tool open on your screen before the candidate joins. Do not share your screen — keep this visible to you only.
🔗
Open the compiler link in a separate browser tab now:
Python (OneCompiler): https://onecompiler.com/python
💬
Have Microsoft Teams chat open with the candidate. You will paste the data setup code and compiler link via Teams chat — never by sharing your screen.
📝
Go to Page 3 (Score Sheet) and fill in candidate name, role and date before the interview starts.
🔍
Preview the questions on Page 2. Each difficulty section has its own data block — copy the appropriate data code from Page 2 when you start that section.
🐍
Each data section uses different DataFrames. Easy uses a sales DataFrame, Medium uses an orders DataFrame, and Hard uses employees + attendance DataFrames.
⚠️
Privacy ReminderNever share your screen. The candidate should only see what you deliberately paste into Teams chat — the data setup code and the compiler link.
Section 2 — Conducting the Interview
1️⃣
Always start with Easy questions. These gauge baseline Pandas competence. If the candidate cannot answer Easy questions correctly, politely conclude the interview.
2️⃣
Progress Easy → Medium → Hard. Each level uses different data — paste the new data block when switching levels.
3️⃣
For each question, copy the data code from Page 2 and paste in Teams chat. Ask the candidate to run it first, then answer the question.
4️⃣
Hints are allowed but reduce the score. Give syntax hint first. Give logic hint only if still stuck. Never give hints on Easy questions.
5️⃣
Aim for at least 2 Easy + 2 Medium + 2 Hard per session. The score sheet on Page 3 has all 14 questions — mark unused ones as "Did Not Ask".
🤝
Courtesy NoteIf concluding early due to poor performance, always thank the candidate sincerely and advise that the team will be in touch. Let HR handle feedback communications.
